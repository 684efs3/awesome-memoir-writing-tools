# Contributing

Thanks for helping improve this list.

- One tool per pull request, added to the section where it fits best, in a sensible position among similar tools.
- Use the official site link and a short, neutral one-line description.
- Tools must be useful for writing, recording, producing, or publishing memoirs and life story books, and must be actively maintained.
- Format: `- [Name](https://link) - Description.`
- Please explain in the pull request what the tool does and why it fits.
- No affiliate or tracking links.
